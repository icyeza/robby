# UI mockups

Static, clickable HTML mockups of the Robson Readiness web app: every screen and state, with one shared stylesheet (`assets/styles.css`) and a small script (`assets/mockup.js`). Open `index.html` in a browser; no server or build step is needed.

All figures, facilities and reference values are invented placeholders. Nothing here is real patient or facility data.

Check the pages with `python ui-mockups/tools/check_mockups.py` from the repository root.

Screenshots of every screen (desktop at 1440 px wide, plus the sign-in and result screens at phone width) are in [`screenshots/`](screenshots/). Regenerate them with headless Edge or Chrome if the pages change.
